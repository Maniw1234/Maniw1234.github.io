Bluey / Googly Eyes

concept · in development

A cross-device AI computer-use assistant concept: a Windows desktop app and a mobile companion, fronted by an animated blue dome character with a star crown and tracking eyes.

  • Windows desktop
  • Mobile companion
  • Voice commands
  • AI
View details

Objective

Design an AI assistant that works across a Windows PC and a phone: you speak to it, it understands what's on your screen, and it can act on the desktop for you.

Concept features

  • Voice commands as the main way to interact.
  • Visual awareness of what's on the desktop.
  • Desktop interaction, so the assistant can act on the computer.
  • A mobile companion connected to the desktop app.
  • An animated companion with distinct listening and processing states.

Character design

A blue, dome-shaped character with a five-point star crown and expressive eyes that track movement. Its look changes to show when it's listening and when it's processing.

Status

A concept and ongoing development effort. These features describe the design goals; they aren't presented as finished or production-ready.

Hatzolah Live 3D Map

independent project

An interactive live map that combines MapLibre map rendering with a Three.js 3D ambulance and animated crew elements, built for real-time visualization.

  • MapLibre
  • Three.js
  • 3D assets
  • Real-time
View details

Objective

A live map view that makes activity easy to follow at a glance, using 3D elements instead of flat markers.

Key features

  • Interactive map rendering with MapLibre.
  • A three-dimensional ambulance model rendered with Three.js.
  • Animated crew elements.
  • Real-time visualization and interactive presentation.

Technical approach

MapLibre provides the base map, and Three.js renders the 3D assets so they sit on the map and animate within it.

Note

An independent personal project. It isn't an official product of, or endorsed by, any Hatzolah organization. Operational data and feed sources are intentionally left out.

Hatzolah Archive Uploader

Hatzolah Archive Uploader is a personal, single-user tool run by its owner. It uploads audio archive files and their metadata from the owner's own collection to the owner's own Google Drive, using the Google Drive API. It has no other users and no public sign-up, and it does not collect, store, or share anyone else's data.
