AI assistant Concept · in development

Bluey / Googly Eyes

A cross-device AI computer-use assistant concept: a Windows desktop application paired with a mobile companion, fronted by an animated character.

purpose
Explore an assistant you can talk to that can see and act on your desktop, with a friendly character that shows what it is doing.
technical_focus
Voice commands, visual awareness, desktop interaction, and an animated companion interface with listening and processing states.
  • Windows desktop app
  • Mobile companion
  • Voice commands
  • Computer use
  • Character animation
Project details bluey/

Objective

Design an AI assistant that works across a Windows PC and a phone: you speak to it, it understands what is on your screen, and it can carry out actions on the desktop for you.

Concept features

  • Voice commands as the main way to interact.
  • Visual awareness of what is on the desktop.
  • Desktop interaction, so the assistant can act on the computer.
  • A mobile companion that connects to the desktop application.
  • An animated companion interface with distinct listening and processing states.

Character design

A blue, dome-shaped character wearing a five-point star crown, with expressive eyes that track movement. Its visual state changes to show when it is listening and when it is processing. The illustration on this card is a simplified sketch of that concept; move your pointer over it to see the eye tracking.

Technical approach

Two parts: a Windows desktop application that handles computer interaction, and a mobile companion. The character interface is the visible layer that communicates the assistant's state.

Status

Concept and ongoing development effort. The features above describe the design goals; they are not presented as complete or production-ready.

Hatzolah Live 3D Map

An interactive live map that combines map rendering with a three-dimensional ambulance and animated crew elements.

purpose
Present live activity visually, in a way that is easier to follow than plain lists or text.
technical_focus
MapLibre for map rendering, Three.js for the 3D ambulance and crew, and real-time visualization tying the two together.
  • MapLibre
  • Three.js
  • 3D assets
  • Real-time visualization
Project details live-3d-map/

Objective

Build a live map view that makes activity easy to understand at a glance, using 3D elements rather than flat markers.

Key features

  • Interactive map rendering with MapLibre.
  • A three-dimensional ambulance model rendered with Three.js.
  • Animated crew elements.
  • Real-time visualization and interactive presentation.

Technical approach

MapLibre provides the base map. Three.js renders the 3D assets so they sit on the map and animate within it, combining map rendering, 3D assets, and live updates in one view.

Note

An independent personal project. It is not an official product of, or endorsed by, any Hatzolah organization. Operational data, feed sources, and other sensitive details are intentionally left out of this portfolio.

Objective

Build a shipping-tracking application whose interface is easy to navigate and behaves predictably.

Key areas

  • Displaying tracking information clearly.
  • Page navigation across the app.
  • Interface behavior and interaction details.

Hatzolah Archive Uploader

Part of this work is Hatzolah Archive Uploader, a personal, single-user tool run by its owner. It uploads audio archive files and their metadata from the owner's own collection to the owner's own Google Drive, using the Google Drive API. It has no other users and no public sign-up, and it does not collect, store, or share anyone else's data.
